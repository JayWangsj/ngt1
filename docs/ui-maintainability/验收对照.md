## 已完成的维护性迁移

- 公共 Button 语义变体、弹窗布局和表单控件样式集中到 UI 组件样式模块。
- 库存统计、历史卡片、流水状态、空状态、批量操作控件等重复样式迁入组件或业务模块。
- BatchControls 的按钮基础、危险操作和结束操作状态现在由组件 CSS Module 管理；价格新增服务按钮与批量按钮使用公共 `ghost` 悬停背景。
- 价格规则编辑器的列表容器、标题行、规则行、批量/悬停/激活状态及手机断点样式已迁入 `price-rule-list.module.css`；保留现有全局 class 作为测试和兼容标记。
- RecordIcon 的尺寸、编辑/删除颜色及悬停/聚焦反馈已迁入 `ui/record-icon.module.css`；父行控制图标显隐的交互规则仍由对应业务行管理。
- 公共 `BackButton`、客户详情返回按钮与零售历史详情返回按钮外观已迁入 `ui/back-button.module.css`，全局返回按钮视觉覆盖已移除；零售弹窗的紧凑间距继续由历史业务模块控制。
- `.dialog-actions` 的基础布局已迁入 `ui/dialog.module.css`；九处表单、订单和库存操作行显式绑定共享模块类，全局基础规则已删除。
- 价格规则编辑器的网格布局与粘性操作行已迁入 `price-rule-editor.module.css`，移除了对应的全局页面选择器。
- 客户详情弹窗的外层溢出和内容滚动限制已迁入 `customer-detail-dialog.module.css`，清除了对应的全局 `:has()` 规则。
- 故障目录管理弹窗正文的高度、溢出和内边距已迁入 `fault-catalog-manager.module.css`，移除全局正文覆盖。
- 系统更新确认弹窗的专用宽度、正文布局和图标样式已迁入 `system-update-dialog.module.css`，清除对应全局样式。
- 零售收款成功弹窗的正文、图标、按钮组和标题定位已迁入 `retail-success-dialog.module.css`，清除对应全局样式。
- 删除确认弹窗共用的正文与危险图标样式已集中到 `ui/dialog.module.css`，客户、目录管理和零售历史弹窗显式使用共享类。
- ProductForm 与快速服务订单编辑表单显式使用 `ui/dialog.module.css` 的基础表单布局，全局 `.dialog-form` 规则已删除。
- FormDialog 现在等待客户端 hydration 完成再挂载 portal，避免零售销售历史深链接首次打开时出现服务端与客户端标记不一致。
- 月度收据弹窗移除了调用方重复的客户端挂载判断，统一使用 FormDialog 的挂载行为。
- 为库存、零售、客户、设置、订单等受影响流程补充或更新了有针对性的视觉回归覆盖。
- 新增 [NGT 前端 UI 开发规范](../NGT前端UI开发规范.md)，记录按钮、弹窗、样式职责和测试要求。
- 库存筛选浮层测试改为检查实际使用组件，避免隐藏 fixture 造成的假阳性。
